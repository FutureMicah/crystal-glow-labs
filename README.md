# Lumina Finance

Ultra-premium, glassmorphism + frosted crystal UI with soft volumetric lighting, subtle iridescent borders, and living 3D elements. Fully responsive across mobile (375–430 px), tablet (768–1024 px), and desktop (1440–1920 px+). Every interaction is functional, real-time, and production-ready. No mock-ups.

Core Visual Language (extracted & elevated from the reference)

•  Soft pearl-white / champagne frosted glass panels with 20–40 % opacity, multi-layer Gaussian blur, and inner specular highlights.

•  Ultra-thin platinum and rose-gold metallic accents.

•  Floating 3D credit-card assets with realistic thickness, embossed Visa hologram, micro-perforations, and dynamic light refraction.

•  Subtle particle systems (golden dust, soft light orbs) that react to touch/cursor.

•  Custom 3D characters: elegant, gender-fluid digital avatars in tailored metallic suits that appear as living assistants, react with micro-expressions, and can be customized.

•  Typography: ultra-light geometric sans for numbers, elegant high-contrast serif for headings, perfect optical sizing.

•  Micro-animations everywhere: cards tilt in 3D on hover/tilt, charts draw themselves with elastic easing, balances count up with satisfying haptic-style feedback, swap arrows morph and spin with fluid physics.

Micro-interactions

•  Buttons and cards have multi-stage press responses: scale down 4 %, emit soft golden ripple, then elastic rebound with a tiny metallic “click” haptic.

•  Balances and numbers use kinetic typography that gently pulses with market volatility; digits flip like mechanical flip-clocks when values change.

•  Charts are not static: the line is a glowing energy ribbon that continuously flows, emits particles on peaks, and reacts to finger/cursor proximity by slightly lifting in 3D.

•  Token icons are true 3D models that slowly rotate, catch light, and morph during swaps with liquid-metal transitions.

•  Background volumetric clouds drift and react to device gyroscope or mouse movement; light rays shift in real time.

•  Success states trigger full-screen crystalline explosions that reform into the next screen elements.

•  Error states use a soft red pulse + 3D character that leans in with a concerned expression and offers one-tap recovery.

Macro & Scene Animations

•  Screen transitions are shared-element morphs with spring physics and parallax depth layers.

•  Loading states grow crystalline structures that dissolve into content.

•  Idle state: subtle ambient life – floating dust motes, occasional soft light flares, and 3D characters performing small breathing/idle animations.
